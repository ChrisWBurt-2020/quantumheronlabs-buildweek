01 / LISTEN + HERON PRESS LIVE · PRIVATE

Books you can
listen to and follow.

Listen plays narrated editions produced by Heron Press, synced to the text in a read-along view, served from a local library. It is a real multi-user system: two readers are bound today, each at their own pace, and personal state fails closed for anyone not bound — an unbound device sees the library, never another reader's place in a book.

  • 01Narrated editions with chapter-level text sync
  • 02Multi-reader, per-reader state, fail-closed privacy
  • 03Runs on phone and TV from the home library
  • 04Status: live for bound readers — private, no public demo
02 / STUDY LOOP LIVE · PRIVATE

Learn, reframed:
the Study Loop.

What Build Week called Learn grew into the Study Loop (the Renaissance System): spaced review across multiple lanes, sized to the session you actually have, graded only on real answered reviews. A public demo with fictional sample data shows the shape — the real system, and its data, stay private.

  • 01Learn → practice → recall → review, source-tied
  • 02Feed-to-Study-Loop integration shipped in October — shown here as integration and hardening; this page does not claim Feed-driven usage numbers
  • 03Status: live and private (tailnet-only)
  • 04Public path: Try the Learn demo — sample data ↗
03 / FIELD + SHARE-TO-HERON + NOW LIVE · PRIVATE

Share from a phone.
Find it on Now.

Heron Field is the phone front door. Share a page or a note and the durable share queue files it, runs research where a worker exists, and surfaces the result on the Now tab — confirmed on a real device, not just a server log. Honestly bounded: Research has a worker; Remember is filing; Task is a deliberate no-op; Evaluate has no worker yet, and this page does not claim otherwise.

  • 01Durable share queue — a share is not fire-and-forget
  • 02Research results filed against the original observation
  • 03Now refreshes on open, on the device
  • 04Status: live and private — shipped and device-confirmed November 10, 2026
04 / BOOK CLUB LIVE · PRIVATE

A worked example:
a two-reader book club.

Book Club is Listen and Press pointed at one concrete job: two readers, one shared book, released in gated blocks of three units, each reader moving at their own pace. It launched November 4, 2026. A small, legible product built from the same parts — that is the point of a platform.

  • 01Shared long-form reading, gated in blocks
  • 02Per-reader pace and state, on the multi-reader Listen base
  • 03Status: live and private for its two readers
05 / LOCAL CORPORA LIVE · LOCAL

57M+ records,
on local hardware.

The knowledge base under Heron is not an API call. Wikipedia (6.6M articles), PubMed (40.0M records), and case law (10.9M opinions) sit in a local full-text index of about 189 GB, searchable on the machine that owns them. The honest bound: this is full-text search at scale — semantic embeddings cover part of the corpus and are not claimed over all of it.

  • 0157M+ records, local — no per-query API dependency
  • 02Full-text (FTS) claim only, as stated
  • 03Status: live locally; not a public search endpoint
06 / PERSONAS + ROUTING LIVE · PRIVATE

23 live personas.
One cost governor.

Twenty-three live voice personas, human-gated, routed to 6 outputs — scheduled briefings, study voices, and grounded writers, each with a named owner and an off switch. Underneath, models are not a logo: a local router (9router) sends work to governed combinations — a build lane and a fast lane, local-first — with stronger cloud models used only where they earn it, and spend visible in one place. That routing and governance story is the same one offered to contracting clients.

  • 0123 live personas, human-gated, routed to 6 outputs
  • 02Model routing + cost governor, local-first
  • 03No single-model centre — the July single-model framing is retired
  • 04Status: live and private on the home system

03 HOW IT WORKS

AI where judgment helps.
Deterministic code everywhere else.

Models help turn selected material into useful structure; software owns identity, source state, schedules, progress, and the interface. Routing is governed: local-first lanes for build and fast work, cloud models only where they earn it, spend visible and capped.

01

Human-selected

Nothing enters the loop until a person decides it matters.

02

Governed routing

Model choice is a policy with a budget, not a default to the biggest model.

03

Private by default

Real data stays on private surfaces; public pages demonstrate with sample data, labelled as such.

04

Approval-gated action

Anything consequential waits for a human decision, and the decision is receipted.
